## 核心概念

### 1. 全量元计算算子（O）

系统的基本计算单元，由四个分量构成：


| 分量 | 名称 | 角色 |
|------|------|------|
| **A** | 大循环流向 (σ ∈ {+1, -1, 0}) | 决定宏观流动方向：流出（扩张）、流入（收缩）、平衡 |
| **B** | 确定-不确定结构体 (β, R) | 承载算子的存在量强度：β 为确定性值，R 为不确定性度 |
| **C** | 层-填充结构体 (N_int, f) | 描述算子的维度层级与填充状态 |
| **D** | 维度规则库 | 定义维度的边界类型、步长单位与流向规则 |

### 2. 正态分布基底

不是随机噪声，而是描述「自然趋势」与「典型性」的度量工具。系统的演化趋势函数基于正态分布构造，使参数增长呈现自然的钟型曲线特征。

### 3. 自组织

层结构、耦合强度、参数权重均由系统状态涌现，无需外部指定。算子根据其虚部 Im(V) 自动聚类分层，层界由动态计算的 δ_Im 阈值决定。

### 4. 线子对系统

| 类型 | 名称 | 作用 |
|------|------|------|
| **一级线子对 (dQ₁)** | 算子↔算子 | 两个算子之间的直接耦合桥梁，描述「变化」 |
| **二级线子对 (dQ₂)** | 算子对↔层 | 一对算子与所在层之间的关系桥梁，描述「变化的变化」 |

这构成了**微积分的微积分**哲学——一级线子对刻画变化本身，二级线子对刻画变化的速率与典型性偏移。

### 5. 层（Layer）

若干 Im(V) 值相近的算子构成一个簇（层）。系统通过标准差驱动的递归聚类算法自动确定层界，每个演化周期结束后动态更新。

### 6. 满态与全局事件

当全局层数 k 达到体系最大容量 K 时，系统进入满态，触发以下三种事件之一：

- **事件 A（层合并）：** 当几乎所有算子流向同向时
- **事件 B（全局迁跃）：** 当正负流向均衡时
- **事件 C（体系重构）：** 当流向剧烈波动时
